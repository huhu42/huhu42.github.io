# Nikki Hu — Portfolio

Personal portfolio website hosted with GitHub Pages.

## Development

This is a static HTML/CSS site with no build dependencies. Open `index.html` in a browser to preview.

## Publishing

Once merged into `main`, enable GitHub Pages in **Settings → Pages**, choosing **Deploy from a branch**, `main`, `/(root)`. The site will be available at https://huhu42.github.io/.

A custom domain can be added later under GitHub Pages settings. GitHub Pages normally redirects the github.io URL to the custom domain while keeping both addresses reachable.
